# TLAMATINI — Resumen de Requisitos Funcionales

> Plataforma web para mujeres en tecnología en México. 
> Documento de requisitos: Perfiles de usuarias y Motor de Matching

## Módulo 1 — Perfiles de Usuarias

- Crear un sistema de registro e inicio de sesión (incluyendo Google).
- Guiar a la usuaria para completar su perfil.
- Permitir gestionar información personal y profesional básica.
- Definir experiencia, especialización y preferencias laborales.
- Administrar habilidades técnicas con niveles de dominio.
- Crear y mostrar un portafolio de proyectos.
- Registrar experiencia laboral, educación y certificaciones.
- Configurar visibilidad y privacidad del perfil.
- Asegurar buen rendimiento, accesibilidad y diseño responsive.

---

## Módulo 2 — Motor de Matching

- Permitir a empresas publicar vacantes.
- Crear un algoritmo que conecte perfiles con oportunidades laborales.
- Calcular compatibilidad basada en habilidades, experiencia y preferencias.
- Mostrar recomendaciones de empleo ordenadas por relevancia.
- Permitir filtrar, guardar y explorar vacantes.
- Mostrar brechas de habilidades para mejorar el perfil.
